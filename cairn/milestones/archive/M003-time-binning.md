# M003: Time binning

**Status:** done (2026-09-15, PR #3 https://github.com/jmgirard/chromodoris/pull/3)

**Goal:** Let users bin every series onto a common time grid of a stated width before the bands are computed, so continuous ratings sampled faster than they vary plot as readable ribbons.

**Outcome:** Exported `bin_series(data, id, time, value, width)`: bin `k = floor(time / width)`, row at midpoint `(k + 0.5) * width`, value the mean of non-missing values, no row for an all-NA or empty bin. `bin` argument on `stat_chromodoris()` and `chromodoris()` applies the same rule per `group` in `compute_panel` before summarising, through the shared `bin_core()`. `check_bin()` validates at `bin_series()`, at `chromodoris()` call time, and in the stat's `setup_params`, which also aborts on the no-group sentinel. Default path pinned to `tests/testthat/fixtures/stat-default-48e2e88.rds`, regenerated by `data-raw/stat-default-fixture.R` from a `git archive` of 48e2e88. README example and figure at `bin = 0.5`, NEWS entry, pkgdown "Preparing data" section, DESIGN Function Families and Architecture updated.

**Decisions:** none promoted. Plan-gate choices in the work log: per-series binning over edge smoothing, an exported function plus an argument, bin midpoints over starts, width in time units over Hz.
